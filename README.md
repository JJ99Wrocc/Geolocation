 Geolocation – Aplikacja do lokalizacji użytkownika

Geolocation to nowoczesna aplikacja webowa stworzona w technologii React, która umożliwia użytkownikom łatwe i szybkie ustalenie ich aktualnej lokalizacji geograficznej. Projekt wykorzystuje wbudowane API przeglądarki do uzyskania współrzędnych GPS, a następnie wyświetla je w przyjaznym interfejsie użytkownika.

 Technologie

React – biblioteka JavaScript do budowy interfejsów użytkownika

HTML5 Geolocation API – do pozyskiwania lokalizacji urządzenia

CSS – stylizacja komponentów

 Funkcjonalności

Automatyczne wykrywanie lokalizacji użytkownika

Wyświetlanie współrzędnych geograficznych (szerokość, długość geograficzna)

Prosty, responsywny interfejs użytkownika

 Uruchomienie projektu

Sklonuj repozytorium:

git clone https://github.com/JJ99Wrocc/Geolocation.git

npm install

npm start


Aplikacja będzie dostępna pod adresem http://localhost:3000
.

 Testowanie

Aby uruchomić testy jednostkowe:

npm test

 Cel projektu

Celem projektu było stworzenie prostego narzędzia do demonstracji możliwości API Geolocation w przeglądarkach internetowych. Aplikacja może być punktem wyjścia do bardziej zaawansowanych rozwiązań, takich jak mapy interaktywne czy aplikacje mobilne.
